How it works

Next.js App Router splits your app across server and client. React DevTools only sees the client fiber tree.

1

Static analysis

Parse your source files to build a route tree with props, hooks, and server queries.

2

Runtime inspection

Read live fiber state/props in the browser for what’s actually rendered right now.

3

Merge at client “bridge” points

Combine both sources so the server hierarchy and client runtime meet in one tree.

What you get route-*.json 
{
  "route": "/dashboard/settings",
  "tree": {
    "name": "RootLayout",
    "kind": "server",
    "children": [
      { "name": "StandardLayout", "kind": "server" },
      { "name": "SettingsPage", "kind": "client" }
    ]
  },
  "dataFlow": { "props": "sources + traces" }
}

The exact schema depends on the analyzer output, but the goal stays the same: synthesized, relational context.

Get started

Install

pnpm install

Then run the commands below from this repo.

Live overlay proxy

pnpm serve --proxy http://localhost:3000 --project ~/Code/my-nextjs-app

Open http://localhost:9876 instead of your app port.

Route snapshot

pnpm route ~/Code/my-nextjs-app /dashboard/settings

Generates JSON + a static HTML visualization + an injectable overlay script.

Full repo analysis

pnpm analyze ~/Code/my-nextjs-app --only deps,components,routes

Outputs artifacts to repo-analysis-output/.
